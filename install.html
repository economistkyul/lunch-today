앱스토어 설치 없이, 아이콘 하나로 바로 열려요.

휴대폰 카메라로 찍으면 바로 열려요
앱 열기

아이폰

  1. Safari로 주소를 엽니다.
  2. 아래쪽 공유 버튼(네모에 ↑)을 누릅니다.
  3. 홈 화면에 추가 → 추가

갤럭시·안드로이드

  1. Chrome이나 삼성 인터넷으로 주소를 엽니다.
  2. 화면 위 안내의 홈 화면에 추가를 누르거나
  3. 메뉴 ⋮(삼성 인터넷은 ≡) → 홈 화면에 추가 / 앱 설치

카카오톡으로 받았다면

  1. 카카오톡 안에서는 설치가 안 돼요.
  2. 오른쪽 아래(또는 위) ⋯ → 다른 브라우저로 열기
  3. 열린 Safari·Chrome에서 위 방법대로 추가합니다.

홈 화면 아이콘으로 열면 주소창 없이 앱처럼 뜨고, 투표·후기도 그대로 이어져요. 식당 정보가 바뀌면 다음에 열 때 자동으로 최신이 됩니다. 처음 연 브라우저(기기)마다 닉네임을 한 번 정해야 해요.
